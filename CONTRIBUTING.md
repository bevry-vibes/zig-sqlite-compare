# CONTRIBUTING

Thanks for your interest in improving `zig-sqlite-compare`.

## Adding a new candidate library

Each library lives in its own top-level directory. To add one:

1. **Create the directory**: `<lib-slug>/` with `src/main.zig`, `build.zig`, `build.zig.zon`.

2. **Write the test program** in `src/main.zig`. It must:
   - Read the DB path from the `ZIG_SQLITE_COMPARE_DB` env var, falling back to `../../../fixtures/sample.db`.
   - Open the DB (read-only when the lib supports it).
   - Run these two queries (or equivalents that touch the same tables):
     ```sql
     SELECT id, slug, title FROM session LIMIT 5;
     SELECT count(*) FROM project;
     ```
   - Exit 0 on success.
   - On a SELECT API bug, fall back to `INSERT`/`DELETE` (still forces SQLite C linkage).

3. **Write `build.zig`** with these targets and flags:

   ```zig
   const targets = [_]struct { name: []const u8, query: std.Target.Query }{
       .{ .name = "linux-x86_64",   .query = .{ .cpu_arch = .x86_64,   .os_tag = .linux,   .abi = .musl } },
       .{ .name = "linux-aarch64",  .query = .{ .cpu_arch = .aarch64,  .os_tag = .linux,   .abi = .musl } },
       .{ .name = "macos-aarch64",  .query = .{ .cpu_arch = .aarch64,  .os_tag = .macos                } },
       .{ .name = "windows-x86_64", .query = .{ .cpu_arch = .x86_64,   .os_tag = .windows, .abi = .gnu  } },
   };

   pub fn build(b: *std.Build) void {
       for (targets) |t| {
           const target = b.resolveTargetQuery(t.query);
           const optimize = .ReleaseSmall;

           // declare dependency(ies) per the library

           const root_mod = b.createModule(.{
               .root_source_file = b.path("src/main.zig"),
               .target = target,
               .optimize = optimize,
               .strip = true,
               .link_libc = true,  // required for std.c.getenv
           });
           // root_mod.addImport(...);

           const exe = b.addExecutable(.{
               .name = b.fmt("<your-lib-slug>-{s}", .{t.name}),
               .root_module = root_mod,
           });
           b.installArtifact(exe);
       }
   }
   ```

4. **Pin the dependency in `build.zig.zon`** with the exact hash from `zig fetch`. Use a separate fingerprint (let `zig build` print one and copy it in).

5. **Test**:

   ```bash
   cd <your-lib-slug>
   zig build --prefix .
   ./bin/<your-lib-slug>-macos-aarch64
   ```

6. **Add the candidate to `compare.sh`** by appending its slug to the `candidates` array.

7. **Update the [README comparison tables](README.md#the-comparison)** with the new row(s) under "Size + correctness matrix", "Strategies compared", and "Per-candidate detail" as appropriate.

## Adding a new target

Edit the `targets` array in every `build.zig`. Keep them in sync — each candidate is independent.

Common additions: `windows-aarch64`, `macos-x86_64`, `linux-x86` (32-bit).

## Commit conventions

Follow [bevry-labs/skills/commits.md](https://github.com/bevry-labs/skills/blob/main/commits.md):

- Conventional Commits 1.0.0
- One logical change per commit
- ≤ 50 char subject (hard cap 72)
- Body explains *why*, not *what*
- Mandatory `Co-authored-by:` trailer, generated fresh per-commit by:

  ```bash
  # build agent-detect first:
  ( cd ../agent-detect && zig build )
  ../agent-detect/zig-out/bin/agent-detect trailer
  ```

## Testing

```bash
# fetch deps + build + measure
./scripts/bootstrap.sh
./scripts/compare.sh

# build + measure a single candidate
./scripts/bootstrap.sh <slug>
./scripts/compare.sh --only=<slug>
```

If a binary errors out, check that the test DB exists at `fixtures/sample.db`. `compare.sh` restores it from `fixtures/seed.sql` before every run.

**Vendoring policy:** do not commit `candidates/*/zig-pkg/`, `candidates/*/.zig-cache/`, or `candidates/*/bin/` directories. They're regenerated by `./scripts/bootstrap.sh`. Pin exact dependency URLs and hashes in `build.zig.zon`.

## Reporting issues

Open an issue on the GitHub tracker with:

- The output of `./compare.sh`.
- The Zig version (`zig version`).
- The OS and architecture (`uname -a`).
- The exact candidate that misbehaved.
